# Hotel Media Player — Windows

پلیر کیوسک ویندوز (Electron) که پورتال هتل را تمام‌صفحه نشان می‌دهد.

## اجرا

```bash
npm install
npm start            # حالت توسعه (F12 = DevTools، F5 = reload)
npm run build        # نصب‌کننده NSIS در dist/
npm run build:ia32   # نسخه ۳۲ بیتی برای مینی‌پی‌سی‌های قدیمی
```

## بخش تنظیمات

پنجره‌ی راه‌اندازی (اولین اجرا، یا از Tray → «تنظیمات / Setup») شامل:

| تنظیم | پیش‌فرض | اثر |
|---|---|---|
| اجرای خودکار با روشن شدن ویندوز | روشن | `app.setLoginItemSettings({openAtLogin})` — فقط در نسخه‌ی نصب‌شده |
| صفحه به خواب نرود | روشن | `powerSaveBlocker.start('prevent-display-sleep')` |
| نشانگر ماوس پنهان شود | روشن | تزریق CSS `cursor:none` روی صفحه |
| همیشه بالاتر از پنجره‌های دیگر | روشن | `setAlwaysOnTop` |
| تلاش دوباره بعد از خطا | ۱۰ ثانیه | فاصله‌ی بارگذاری مجدد بعد از `did-fail-load` |
| تازه‌سازی خودکار | خاموش (۰) | `reloadIgnoringCache` هر N دقیقه |

تنظیمات در `%APPDATA%/hotel-media-player/config.json` ذخیره می‌شود.

## رفتارهای پایداری

- **تک‌نمونه‌ای**: ویندوز هنگام ورود ممکن است برنامه را دو بار اجرا کند؛
  `requestSingleInstanceLock` جلوی دو پخش همزمان را می‌گیرد.
- **بازیابی خودکار**: خطای بارگذاری، از دست رفتن renderer و پنجره‌ی
  `unresponsive` هر سه به بارگذاری مجدد ختم می‌شوند.
- **بدون راه فرار**: منوی راست‌کلیک، popup و ناوبری خارج از سرور بسته‌اند.

## نصب روی دستگاه هتل

1. `npm run build` و کپی `Hotel Media Player Setup <version>.exe` روی دستگاه.
2. نصب (نیازی به Administrator نیست).
3. آدرس سرور و کد صفحه را وارد و «ذخیره و شروع پلیر» را بزنید.
4. در همان پنجره «اجرای خودکار با روشن شدن ویندوز» را روشن بگذارید.
