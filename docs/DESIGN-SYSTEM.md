# انطباق پنل با دیزاین‌سیستم سماع

منبع استاندارد: [github.com/kish210/sama-design-system](https://github.com/kish210/sama-design-system) — نسخهٔ **v1.3.0**
(فایل‌های مرجع: `STANDARD.md`، `tokens/tokens.json`، `styles.css`)

این سند می‌گوید چه چیزی اعمال شد، چه چیزی عمدا اعمال **نشد**، و چرا.

## ۱) چطور اعمال شد: یک لایهٔ توکن، نه بازنویسی

پنل ۵۰ صفحه دارد که همه با توکن‌های `public/assets/css/design-system.css` ساخته شده‌اند. بازنویسی آن
یعنی دست‌زدن به همهٔ صفحه‌ها و ریسک شکستن چیدمان. در عوض:

```
design-system.css        ← ساختار و کامپوننت‌ها (دست‌نخورده)
        ↓
sama.css                 ← فقط مقادیر: رنگ، شعاع، فوکوس، چگالی
```

`sama.css` بعد از `design-system.css` بار می‌شود و **همان نام‌های موجود** (`--brand-*`، `--ok`، `--r-*`)
را با پالت رسمی پر می‌کند. نتیجه: رنگ دکمه‌ها، لینک‌ها، وضعیت‌ها و نوار کناری خودکار عوض می‌شود، بدون
اینکه یک صفحه دست بخورد.

### نگاشت توکن

| توکن پنل | مقدار سماع | کاربرد |
|---|---|---|
| `--brand-500` | `#4B5F97` (`--blue-600`) | دکمهٔ اصلی، لینک، فوکوس |
| `--brand-600` | `#324A7A` (`--blue-700`) | hover، تاپ‌بار |

| `--r-sm / --r-md / --r-lg` | `4 / 6 / 8px` | کنترل / کارت / دیالوگ |

نسبت رنگ: **۸۰٪ خنثی / ۱۵٪ برند / ۵٪ وضعیت** — همان قاعدهٔ استاندارد، بخش ۲.

## ۲) چیزهایی که رعایت شد

- **RTL کامل** و فونت Vazirmatn (محلی، بدون CDN — سرور هتل اینترنت ندارد).
- **فوکوس قابل‌مشاهده**: حلقهٔ ۲px آبی برند روی همهٔ عناصر (`:focus-visible`).
- **چگالی لمسی**: هتل‌مدیا در `products.json` با `density: touch` ثبت است؛ روی دستگاه‌های
  `pointer: coarse` حداقل ناحیهٔ لمس ۴۴px اعمال می‌شود.
- **حرکت ۱۵۰–۲۵۰ms** با منحنی `cubic-bezier(.2,.8,.2,1)` و احترام کامل به `prefers-reduced-motion`.
- **جدول‌ها**: هدر چسبان و ارقام `tabular-nums` (کلاس‌های `hm-table` / `hm-num`).
- **تم روشن**: پالت رسمی سماع (`--gray-50` پس‌زمینه، سطح سفید، متن `--gray-900`) برای اپراتور
  لابیِ پرنور.
- **یک دکمهٔ primary در هر فرم** — قاعدهٔ بخش ۷؛ در صفحه‌های تازه رعایت شده.

## ۳) چیزهایی که عمدا اعمال **نشد** — و دلیلش

| مورد استاندارد | چرا نه |
|---|---|
| **تم روشن به‌عنوان پیش‌فرض** | اپراتور هتل شب کار می‌کند و صفحه‌های پنل کنار مانیتورهای پخش نمی‌توانند چشم را بزنند. تم تیره پیش‌فرض می‌ماند؛ تم روشن یک کلیک فاصله دارد. |
| **پوستهٔ ERP (تاپ‌بار ۵۶px، تب اسناد ۳۴px، نوار وضعیت ۲۶px)** | آن پوسته برای سماع‌حساب (WPF دسکتاپ) است. هتل‌مدیا وب + تلویزیون است و ساختار ناوبری خودش را دارد؛ تحمیل تب اسناد، فضای صفحهٔ تلویزیون را کم می‌کند. |
| **کلیدهای F2/F7/F8/F9** | روی تلویزیون و مرورگر لپ‌تاپ اپراتور معنا ندارد. میانبرها در سطح هر صفحه (مثل `command-palette.js`) می‌مانند. |
| **`@import` فونت از Google Fonts** | `styles.css` سماع این را دارد؛ سرور هتل روی VLAN بسته است و فونت باید محلی باشد (`/assets/vendor/vazirmatn`). |
| **شعاع ۴ برای همه‌چیز** | دیالوگ‌های شناور ۸ می‌مانند (استاندارد هم همین را می‌گوید) ولی کارت‌های داشبورد ۶→۱۲ داشتند؛ به ۶ برگردانده شد تا یکدست شود. |

## ۵) ارتقای بعدی

دیزاین‌سیستم با تگ مصرف می‌شود (`v1.3.0`). هنگام ارتقا:

1. `git -C ../sama-design-system fetch --tags && git checkout vX.Y.Z`
2. `tokens/tokens.json` را با `public/assets/css/sama.css` مقایسه کنید (فقط مقادیر).
3. نسخهٔ `hotelmedia` را در `products.json` همان مخزن به‌روز کنید — تا معلوم باشد کدام محصول عقب است.
